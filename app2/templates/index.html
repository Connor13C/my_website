Flask Single Page App - Feature Requester

  • Add a client
  • Delete an existing client
  • Make a new feature request for client
  • Find existing feature requests for client
  • Get feature request by ID
  • Delete existing feature request by ID
Registration and Login are trivialized for demo purposes and do not require email verification. Endpoints are JWT protected. You may make a user freely to play around with the small demo.
***Warning: Too many failed log in attempts will result in IP ban from website since the main server has production grade access banning, so keep failed login attempts to reasonable amount.***
